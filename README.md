# CocktailsApplication

# DevOps CI/CD Web Application 🚀

## Overview
This project is a web application with a fully implemented CI/CD pipeline, using GitHub Actions and Kubernetes.  
It demonstrates the complete DevOps workflow — from code commit to automated build аnd deployment.

## Features
- End-to-end CI/CD pipeline
- Automated build and deployment process
- Containerized application using Docker
- Kubernetes-based deployment
- Infrastructure and deployment automation

## Technologies Used
- GitHub Actions
- Docker
- Kubernetes
- CI/CD

## Project Purpose
This project was developed as an individual practical project to demonstrate hands-on experience with:
- DevOps workflows and best practices
- CI/CD automation using GitHub Actions
- Containerization and orchestration with Docker and Kubernetes

## CI/CD Pipeline Overview
- Code commit triggers the pipeline
- Automated build and containerization
- Image push to container registry
- Automatic deployment to Kubernetes cluster

### Prerequisites
- Docker
- Kubernetes (local or cloud-based cluster)
- GitHub Actions (configured in the repository)
